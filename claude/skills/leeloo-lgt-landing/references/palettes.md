# Кольорові гами

Як зібрати кольори з людини і перевести їх у токени. Читай на кроці брифу «Блок B» і перед
перефарбуванням у кроці 4.

## 1. Як питати про кольори

Клієнт рідко знає, що таке «акцент» і «другий колір градієнта». Тому питай трьома рівнями,
зупиняйся на першому, де є відповідь:

1. **«Є брендбук / фірмові кольори?»** → бери hex-коди звідти: головний = `--accent`,
   другий = `--second`. Якщо дали 3+ кольори — головний той, що на лого/кнопках сайту.
2. **«Скиньте лого або посилання на сайт/Instagram»** → витягни 2 домінантні кольори з лого
   (не з фото), покажи їх hex-кодами і спитай «беремо ці?».
3. **«Нема кольорів — оберіть гаму з каталогу»** → покажи таблицю нижче (номер, назва,
   для кого, два кольори) і попроси номер. Запропонуй один варіант сам, з поясненням за нішею.

Окремо завжди уточни **фон**: темний (dark) чи світлий (light). Гама і тема — незалежні:
будь-яка пара акцент/другий працює на обох фонах, змінюються лише ink-токени та glow.

Після вибору покажи людині компактну картку гами й дочекайся «ок»:
```
Гама: «Бірюза + графіт» · тема light
акцент  #2FB8A6 (крапка, номери, виділення, зірки)
другий  #0E1B3D (градієнт заголовка, кнопки-акценти)
фон     #F5F6F8 / картка #FFFFFF
```

## 2. Каталог готових гам

вказано. Для light-теми `--navy` лишається `#0E1B3D`, крім гам, де вказано інше.

## 3. З двох кольорів у повний набір токенів

1. `--accent` = головний. `--accent-2` = він же, освітлений на ~15–20% (HSL: L +15). Якщо
   головний уже світлий (L > 70%) — навпаки, `--accent-2` темніший на 10%.
2. `--second` = другий колір. `--second-lt` = освітлений на ~20%.
3. `--third` = `--second` або темніший відтінок акценту.
4. **Перерахуй rgba-дублікати акценту** (у шаблоні вони «зашиті» під золото 247,179,43):
   - `.tag .dot` — `box-shadow:0 0 0 4px rgba(R,G,B,.18),0 0 12px rgba(R,G,B,.8)`
   - `.page::after` 1-й градієнт — `rgba(R,G,B,.16)`; 2-й — rgba другого кольору `.30`; 3-й — rgba `--third` `.20`
   - light: `.getlist li .n` — `box-shadow:0 2px 6px rgba(R,G,B,.35)`; `.shell::before` — rgba другого `.28`
   - частини 2+: `.pN-dot` тіні та `.pN-glow` (rgba другого `.26`, третього `.18`)
5. **Контраст.** Колір номерів `.getlist li .n` — текст `#0A0E1F` на акценті: якщо акцент темний
   (бордо, індиго, графіт), перемкни на `color:#fff`. Курсив `.grad` на dark завжди має середній
   стоп `#fff`, на light — `--navy`, тому читається за будь-яких крайніх кольорів.
6. **Дуже світлий акцент на light** (лайм, жовтий, мʼята): для тексту/зірок/`.gh b` бери
   затемнену версію (L −25%), сам акцент лишай для крапки, номерів і glow.

Швидка формула HSL-зсуву в Python, якщо треба порахувати:
```python
import colorsys
def shift(hexc, dl):
    r,g,b = (int(hexc[i:i+2],16)/255 for i in (1,3,5)); h,l,s = colorsys.rgb_to_hls(r,g,b)
    l = max(0,min(1,l+dl)); return '#%02X%02X%02X' % tuple(round(c*255) for c in colorsys.hls_to_rgb(h,l,s))
def rgb(hexc): return ','.join(str(int(hexc[i:i+2],16)) for i in (1,3,5))
# shift('#2FB8A6', .15) -> accent-2 ; rgb('#2FB8A6') -> '47,184,166'
```

## 4. Чого не робити

- Не бери 3+ акцентів: формат тримається на одному акценті й одному другому кольорі.
- Не роби акцентом сірий чи чорний — крапка, номери й зірки зникають. Для «чорно-білих»
  брендів акцент = один живий колір із лого або гама 12.
- Не міняй зелений чекліста (`#46D86A→#22B24E`) під гаму — це семантика «виконано».
- Не фарбуй кнопки месенджерів Leeloo під гаму без `leeloo-design-fit`: у нативній формі вони
  фірмових кольорів Telegram/WhatsApp, і так має бути.
