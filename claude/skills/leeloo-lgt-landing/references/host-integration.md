# Інтеграція з хостом Leeloo (LGT / лендинг тунелю)

## Як Leeloo рендерить сторінку

Лендинг у Leeloo — це стос блоків у розділі **Вміст**: `HTML`, `Форма`, `Текст`, `Зображення`…
Кожен наш «екран» — окремий HTML-блок. Leeloo вставляє вміст блоку всередину свого
контейнера (`#leadgentool-card` → `.adaptive-container`), а **форму підписки** (поле + кнопки
Telegram/WhatsApp + згода) рендерить своїм скриптом як окремий блок `Форма`.

Типова розкладка сторінки з бойових LGT:

```
HTML-блок 1   ← частина 1: бренд + УТП + медіа + докази + «що отримаєте»  (part 1)
Форма         ← нативна форма Leeloo (поле, кнопки месенджерів, згода)
HTML-блок 2   ← частина 2: чекліст «що ви отримуєте» / відгуки           (part 2, префікс p2-)
HTML-блок 3   ← частина 3: відео-фасад + місток                          (part 3, префікс p3-)
Форма (дубль) ← опційно, повторити CTA внизу
```

Із цього випливають три правила.

### Правило 1. Частина 1 володіє сторінкою, частини 2+ — гості

Усі HTML-блоки живуть в одному `document`. CSS з блоку 2 бачить блок 1 і навпаки.
Тому:
- **Частина 1** оголошує `:root{…}` токени, `*{margin:0;padding:0;box-sizing:border-box}`,
  `html,body{margin:0!important;padding:0!important;background:…}` — вона задає фон усієї сторінки.
- **Частини 2+** не мають права на `:root`, `html`, `body`, `*` і будь-які загальні селектори
  (`h2`, `img`, `p`). Усі їхні класи й `@keyframes` — з префіксом (`.p2-wrap`, `.p2-shell`, `p2pulse`),
  токени — локальні змінні на `.pN-wrap`, ресет — `.pN-wrap *{margin:0;padding:0;box-sizing:border-box}`.
  Інакше стилі частин перебʼють одна одну і зламають форму Leeloo, чиї класи `.footer`, `.form-input`
  живуть у тому ж документі.

`scripts/build_lgt.py --part 2 --prefix p2-` перевіряє це автоматично.

### Правило 2. Хак верхнього відступу хоста

Контейнер Leeloo дає зверху ~28–60px порожнього простору. Щоб бренд-бар стояв щільно,
бойові LGT роблять одне з двох (або обидва):

```css
/* спосіб A (yaflu1): підняти .page на висоту відступу, компенсувати в brandbar */
:root{--host-gap:28px}
.page{margin-top:calc(-1 * var(--host-gap))}
.brandbar{padding:calc(var(--host-gap) + 6px) 0 2px}

/* спосіб B (apple-light): зсунути сам контейнер Leeloo */
.adaptive-container{top:-60px}
```
Ставити тільки в **частині 1**. За замовчуванням бери **спосіб A** (він компенсується
всередині нашої верстки й нічого не зсуває у хості). Спосіб B додавай лише якщо після
заливання щілина зверху лишається і при `--host-gap:60px` — це зсув самого контейнера Leeloo,
і при зміні розмітки Leeloo він може обрізати бренд-бар. Якщо після заливання зверху щілина —
збільш `--host-gap` до 40–60px; якщо бренд-бар обрізаний — зменш або прибери спосіб B.
Перевіряти на публічному URL LGT, не в превʼю.

### Правило 3. Форму не верстаємо — вона нативна

Поле email/телефону, кнопки месенджерів і чекбокс згоди рендерить Leeloo. У наших частинах
немає `<form>`, `<input>`, кнопок «Надіслати». Частина 1 закінчується блоком `.getlist`
(«Залишайте заявку, щоб отримати…») — саме під ним у розкладці стоїть блок `Форма`.

Якщо клієнт хоче форму **всередині** дизайну (у колонці, стилізовану під бренд, або продублювати
її в кількох місцях) — це окремий скіл **`leeloo-design-fit`**: він додає слот `.lgt-slot`,
CSS для класів `.lgt-custom-field / .lgt-social-buttons / .footer` і JS перенесення. Для нього в
`:root` частини 1 мають бути `--tg-1/--tg-2`, `--wa-1/--wa-2`, `--ease`, `--f-head`, `--f-body`,
`--ink-1`, `--ink-2` — додай їх одразу, якщо така стилізація планується:
```css
--tg-1:#2AABEE;--tg-2:#229ED9; --wa-1:#25D366;--wa-2:#128C7E; --ease:cubic-bezier(.2,.7,.2,1);
```

## Що ще має бути в кожній частині

- `<meta name="robots" content="noindex,nofollow">` — LGT не має індексуватися окремо від сайту.
- `<link rel="preconnect" href="https://fonts.googleapis.com">` + `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` +
  один `<link href="https://fonts.googleapis.com/css2?family=…&display=swap">`. Дубль у кожній частині
  безпечний (браузер дедуплікує), а окремий блок без нього зламається, якщо його перенесуть.
- `<meta charset>`/`<meta viewport>`/`<title>`/`<link rel="icon">` — Leeloo їх ігнорує або має свої;
  лишай для локального превʼю у браузері, шкоди нема.
- Жодного `localStorage`/`sessionStorage`, зовнішніх JS-бібліотек, `fetch` на сторонні API.

## Медіа та вага

- Дрібне (лого, іконки, логотипи клієнтів ≤ 6 KB кожен, смужка месенджерів) — інлайн base64 через
  `{{asset:…}}` / `{{logos:…}}`. Так блок автономний і не залежить від хостингу.
- Велике (фото креативів, відео, постери) — за URL. Варіанти: медіатека Leeloo (завантажити
  зображення в блок «Зображення», скопіювати URL `static.leeloo.ai/...`), Google Drive
  (`drive.google.com/uc?id=FILE_ID`), Imgur, CDN сайту клієнта.
- Ціль: одна частина ≤ 150 KB, весь лендинг ≤ 400 KB HTML. Скрипт попереджає при > 300 KB.

## Що передати в тунель (опційно)

Якщо екран має вибір (кілька офферів, чіпи-сегменти) і треба знати, що обрав підписник —
запис у кастомні поля йде через `window.leeloo_additional_fields = {custom_fields:[{name, type:'KEYWORD', value}]}`
**до** кліку на кнопку месенджера. Це територія скілів `leeloo-quiz` / `leeloo-calc-builder`;
для звичайного лендингу не потрібно.

## Інструкція клієнту (додавати після коду ЗАВЖДИ)

> **Як розмістити в Leeloo:**
> 1. **Тунелі продажів** → потрібний тунель → **Лендинги** → створіть або відкрийте лендинг.
> 2. Розділ **Вміст** → **+** → блок **HTML** → вставте код *частини 1* → збережіть блок.
> 3. **+** → блок **Форма** (поле + кнопки месенджерів) — саме під частиною 1.
> 4. **+** → блок **HTML** → код *частини 2*; далі так само частина 3.
> 5. Збережіть лендинг і відкрийте **публічне посилання** (не превʼю) на телефоні.
> 6. Якщо зверху є щілина або бренд-бар обрізаний — напишіть, підправлю `--host-gap`.

## Діагностика типових проблем

| Симптом | Причина | Фікс |
|---|---|---|
| Частина 2 «біла» або шрифти інші | у частині 2 нема свого `<link>` шрифтів / локальних токенів | додай `<link>` та змінні на `.p2-wrap` |
| Фон сторінки не темний під формою | `html,body{background}` не заданий у частині 1 | додай у частину 1 |
| Стилі кнопок Leeloo зламались | у частині 2+ загальні селектори (`button`, `p`, `body`) | префіксуй; прогони `build_lgt.py --part 2 --prefix p2-` |
| Відео не автограється на iPhone | нема `muted playsinline` або є звук | додай атрибути; звукове відео → YouTube-фасад |
| Логотипи «стрибають» на стику | доріжка не продублена або різна висота PNG | використовуй `{{logos:…}}`, файли 60px по висоті |
| Щілина зверху | `--host-gap` замалий | 28 → 40 → 60px |
| Курсив у заголовку обрізаний | нема `padding` у `.grad` або `box-decoration-break:clone` | поверни з компонента 3 |
