Install Leeloo in ChatGPT

Connect the Leeloo MCP server (app.leeloo.ai/mcp) to the ChatGPT / Codex desktop app and build marketing foundations, funnels, lead-gen tools and CRM — from chat. Plugin source: github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin.

Fastest path — paste into a new conversation in the Codex desktop app
Read leeloo.ai/chatgpt to install the Leeloo plugin and start building my marketing.

0Host environment gate

This must run in the Codex desktop app on the user's machine. The web app or an isolated remote workspace cannot modify the desktop plugin directory: stop there and send the user to the desktop app with the prompt above. All commands use the Codex CLI bundled with the desktop app — locate it first and replace "<BUNDLED_CODEX>" with its full path (keep the quotes).

"<BUNDLED_CODEX>" --version
git --version

On Windows the Codex runtime may bundle Git at %USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\git\cmd\git.exe — prepend that directory to PATH if git is not found.

1Already connected?

"<BUNDLED_CODEX>" mcp get leeloo --json

Registered and authenticated → skip to step 5. Needs authentication → step 3. Not found → step 2.

2Install

"<BUNDLED_CODEX>" plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin.git --ref main
"<BUNDLED_CODEX>" plugin marketplace list
"<BUNDLED_CODEX>" plugin list --marketplace <MARKETPLACE>
"<BUNDLED_CODEX>" plugin add leeloo@<MARKETPLACE>

<MARKETPLACE> is the name Codex assigned in plugin marketplace list (normally leeloo-ai). Do not open a new thread yet.

3Connect (sign in)

Opens the Leeloo sign-in page in the browser. Sign in at leeloo.ai and click Allow access. If it times out, rerun the same command — one attempt at a time.

"<BUNDLED_CODEX>" mcp login leeloo

4Verify

"<BUNDLED_CODEX>" plugin list --marketplace <MARKETPLACE> --json
"<BUNDLED_CODEX>" mcp get leeloo --json

Expected: the Leeloo row installed, enabled; the MCP entry with URL https://app.leeloo.ai/mcp and an authenticated state.

5Required final step: open the next conversation

The installation conversation cannot reach the newly installed tools. Create the user's next conversation yourself (Codex conversation tools: create_thread, send_message_to_thread, navigate_to_codex_page) with this first message, translated to the user's language:

The Leeloo plugin is installed. Load the leeloo-plugin-basics-codex skill, then ask me for my business materials (briefing transcript, sales brief, price list, cases, site and social links) and build the marketing foundation with the marketing-foundation-builder skill. After I approve it, assemble the tunnel in Leeloo with the tunnel-creator skill.

If setup did not fully succeed, open a recovery conversation instead that reads this page and retries from the failed step — and do not tell the user Leeloo is installed. Full agent contract: docs/codex-install.md.

6Update

"<BUNDLED_CODEX>" plugin marketplace upgrade <MARKETPLACE>

Then start a new conversation and rerun the verification commands.
