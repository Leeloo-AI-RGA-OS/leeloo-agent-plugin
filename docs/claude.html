Install Leeloo in Claude Code

Connect the Leeloo MCP server (app.leeloo.ai/mcp) and build funnels, lead-gen tools, offers and analytics — from chat. Plugin source: github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin.

Fastest path — paste into any Claude Code session
/goal Read leeloo.ai/claude to install and use the Leeloo plugin

0Prerequisites

The Claude Code CLI (v2.1.210+) and Git on PATH:

claude --version
git --version

No claude CLI? Jump to “No CLI” below.

1Already connected?

Check first, to avoid a duplicate registration:

claude mcp get plugin:leeloo:leeloo

Status: ✔ Connected → done. Needs authentication → step 3. Not found → step 2.

2Install

The marketplace clone can take a minute — allow a generous timeout:

claude plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin.git#main
claude plugin marketplace list
claude plugin install leeloo@leeloo-ai

3Connect (sign in)

The plugin ships a helper that starts login and opens the sign-in page in your default browser automatically. Run it in the background:

LOGIN="$(ls -d "$HOME"/.claude/plugins/cache/leeloo-ai/leeloo/*/skills/leeloo-plugin-basics/login-leeloo.sh 2>/dev/null | sort | tail -1)"
sh "$LOGIN" > /tmp/leeloo-helper.out 2>&1 &

Sign in at leeloo.ai and click Allow access. Wait for Authenticated with "plugin:leeloo:leeloo".

4Verify

claude mcp get plugin:leeloo:leeloo

Expected: Status: ✔ Connected, URL https://app.leeloo.ai/mcp. Then open a new session — the Leeloo tools (mcp__leeloo__*) load at session start.

✦No CLI (desktop app)

Install from inside the app with slash commands — no terminal needed:

/plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin
/plugin install leeloo@leeloo-ai

Then open a new session and run /mcp reconnect leeloo → Leeloo → Authenticate → sign in → Allow access.
