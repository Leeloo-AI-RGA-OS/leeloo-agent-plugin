Leeloo.AI × Claude Code

Claude Code install instructions — Leeloo

Install the Leeloo plugin and connect its MCP server from Claude Code. Plugin source (public): github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin. Plugin leeloo@leeloo-ai · MCP https://app.leeloo.ai/mcp.

Fastest path: paste this into any Claude Code session and let it follow the steps. 
/goal Read leeloo.ai/claude to install and use the Leeloo plugin

Prerequisites

The Claude Code CLI, version 2.1.210 or newer, and Git on PATH:

claude --version
git --version

No claude CLI? Jump to “No CLI” at the bottom.

1. Already connected?

Check first, to avoid a duplicate registration:

claude mcp get plugin:leeloo:leeloo

Status: ✔ Connected → done. Needs authentication → step 3. Not found → step 2.

2. Install

The marketplace clone can take a minute — allow a generous timeout:

claude plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin.git#main
claude plugin marketplace list
claude plugin install leeloo@leeloo-ai

3. Connect (sign in)

claude mcp login plugin:leeloo:leeloo

This opens the Leeloo sign-in in the browser and finishes on the localhost callback; sign in at leeloo.ai and click Allow access.

If claude mcp login reports “stdin isn’t a terminal” (agents through a shell tool), use the plugin’s cross-platform helper, which allocates a PTY in the background:

LOGIN="$(ls -d "$HOME"/.claude/plugins/cache/leeloo-ai/leeloo/*/skills/leeloo-plugin-basics/login-leeloo.sh 2>/dev/null | sort | tail -1)"
sh "$LOGIN" > /tmp/leeloo-login.log 2>&1 &

Poll /tmp/leeloo-login.log: open the authorization URL it prints, then wait for Authenticated with "plugin:leeloo:leeloo".

4. Verify

claude mcp get plugin:leeloo:leeloo

Expected: Status: ✔ Connected, URL https://app.leeloo.ai/mcp.

5. Open a new session

Claude Code loads a session’s plugins and MCP tools at session start, so Leeloo’s tools (mcp__leeloo__*) appear in the next session. The connection persists — open a new session and start building.

Update

claude plugin marketplace update leeloo-ai
claude plugin update leeloo@leeloo-ai

No CLI (desktop app without the claude binary)

Install from inside the app with slash commands — no terminal needed:

/plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin
/plugin install leeloo@leeloo-ai

Then open a new session and run /mcp reconnect leeloo → Leeloo → Authenticate → sign in → Allow access.
