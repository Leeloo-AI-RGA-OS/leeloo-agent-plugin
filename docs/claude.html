Needs the Claude Code CLI (claude, v2.1.210+). No CLI? In the app: /plugin marketplace add https://github.com/Leeloo-AI-RGA-OS/leeloo-agent-plugin, then /plugin install leeloo@leeloo-ai, then a new session and /mcp reconnect leeloo.
